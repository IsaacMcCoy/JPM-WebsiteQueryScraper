### JPM-WebsiteQueryScraper

## Requirements

- Node.js
- npm
- tsx (for running server)

## Development

```bash
npm run dev
npm run server
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
## Technologies

- Vue 3
- TypeScript
- Tailwind CSS
- Vite
- Tsx
- Cheerio
- Playwright
